## Відкриті питання

1. **AC 1 (`validate` повертає саме `422`)** — у `SD/03 — API Contract` не описано; підтверджено лише `openapi.yaml:745` і кодом. Діє Confluence; питання лишається відкритим.
2. **Точний текст `rejection_reason` і `message`** у документації не зафіксований, тому перевіряється лише непорожній рядок (`TODO` в API-OP-015).
3. **`200` і `{"ok": true}` для `validate`** (API-OP-013) — підтверджено лише `openapi.yaml`.
4. **Додаткові `GET` на `state = DRAFT`** в API-OP-011 і API-OP-013: у Steps цих кейсів їх немає, але Expected result вимагає «стан лишається `DRAFT`». Запити лише читають дані.
5. **Лід-тайм відраховується від моменту `validate`/`submit`**, а `window_start` виставляється в запиті створення заявки. Для API-OP-013 (запас 1 хв) затримка між цими запитами понад ~1 хв дасть хибний `422`.
6. **Старий ран:** у Testomat наявний ран `SKY-2 · API` (`a4ef85b7`) із результатами попереднього прогону; для цього прогону створено окремий `SKY-2 · API 2026-11-10`.
