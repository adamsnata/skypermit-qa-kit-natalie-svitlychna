# E2E-OP-001: Регистрация через /register с валидными данными → оператор сразу залогинен

**Doc ref:** `04-frontend-spec.md#Operator portal`, `04-frontend-spec.md#Two contracts to hold exactly`, `03-api-contract.md#Authentication & authorisation`, `app/register/page.tsx`, `components/AppHeader.tsx`
**Role(s):** Operator (до регистрации — без учётной записи и сессии)
**Preconditions:**
- Пользователь не залогинен: в шапке видны `operator-login-link` и `operator-register-link`.
- Оператора с email `e2e-op-001@example.com` и `national_id` `E2E-OP-001-NID` в системе нет.

**Steps:**
1. Открыть `/register` (ссылка `operator-register-link` в шапке).
2. Заполнить обязательные поля: `operator-register-email-input` = `e2e-op-001@example.com`, `operator-register-password-input` = `Sky-Permit-2026`, `operator-register-legal-name-input` = `E2E OP 001 Ltd`, `operator-register-national-id-input` = `E2E-OP-001-NID`. Необязательные поля (phone, address, city, postal code) оставить пустыми.
3. Нажать `operator-register-submit-button`.

**Expected result:** Оператор создан и сразу залогинен: в шапке отображаются `operator-session-info` и `operator-logout-button`, а `operator-login-link` и `operator-register-link` больше не отображаются; `operator-register-error` не появляется.

**Rationale:** Позитивный сценарий (happy path) регистрации: по `04#Operator portal` одна общая форма создаёт учётные данные и профиль Operator одним submit и «logging the operator in immediately»; по `03#Authentication & authorisation` `POST /operators` после создания логинит вызывающего (session cookie). Признак залогиненного состояния — набор `data-testid` из `04#Two contracts to hold exactly`. Пароль взят заведомо длиннее лимита: минимальная длина 8 символов есть только в коде (`app/api/v1/operators/route.ts`, `MIN_PASSWORD_LENGTH`), в docs её нет — `TODO: уточнить по требованиям` для отдельного граничного кейса. Что оператор создаётся с `L1`, здесь не проверяется: в UI уровень не отображается, это отдельный API-кейс. Детали реализации, которых нет в docs: после регистрации код перенаправляет на `/operator/pilots`, а `operator-session-info` показывает `legal_name` — в ожидаемый результат не включены.
