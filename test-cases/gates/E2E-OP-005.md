# E2E-OP-005: «Check before submitting» для вікна 04:30–05:15 у KBP-CTR-3 (початок вікна в curfew, кінець після 05:00) → гейт TIME_WINDOW = fail

**Doc ref:** `SD/06 — Business Rules#1.4 TIME_WINDOW`, `SD/06 — Business Rules#4. Zone catalogue`, `SD/06 — Business Rules#6. rule_reference values`, `SD/04 — Frontend Scope#Operator portal`, `components/GateResultsPanel.tsx`, `SD/03 — API Contract#The 422 body`, `SD/03 — API Contract#Gate pipeline (shared by submit and validate)`
**Role(s):** Operator (L2, ACTIVE) — залогінений
**Preconditions:**
- Оператор з `authorisation_level` = `L2` і `status` = `ACTIVE` залогінений.
- Пілот цього оператора: `rating` = `R_ADVANCED`, `certified_on` = дата за 4 місяці до `window_start`.
- ЛА цього оператора: `mtom_grams` = `1500` (смуга `C1`).
- Заявка у `DRAFT` для цього пілота й ЛА: `zone_code` = `KBP-CTR-3`, `requested_altitude_metres` = `70`, `window_start` = 04:30 місцевого часу зони дати, що настає через 9 днів, `window_end` = 05:15 того ж дня (45 хвилин; перші 30 хв — у curfew 23:00–05:00, останні 15 хв — поза ним).
- Браузер працює в часовому поясі `Europe/Kyiv`.
- У браузері відкрито DevTools → Network (запис мережі ввімкнено до кроку 2).

**Steps:**
1. Відкрити сторінку деталей цієї заявки `/operator/requests/<id>`.
2. Натиснути `flight-request-validate-button`.

**Expected result:** Картка `flight-request-gate-result-TIME_WINDOW` показує `fail` (атрибут `data-gate-status` = `FAIL`); у Network відповідь на `POST /api/v1/flight-requests/<id>/validate` має код `422`, а в її тілі `failing_gate` = `TIME_WINDOW` і `rule_reference` = `A-7 §1`.

**Rationale:** Дзеркальний до E2E-OP-004 клас: вікно починається всередині curfew і закінчується після 05:00. За `SD/06#1.4` «no part of the window» може бути в curfew, і перевірка йде поминутно; AC SKY-1 №1 — «будь-яка частина вікна». Значення 05:00 як межа тут не перевіряється (вікно перетинає її, а не лише торкається): чи 05:00 входить у curfew, docs прямо не кажуть — окремий граничний кейс із `TODO: уточнити за вимогами`. Часовий пояс зони в docs не зазначено — `TODO: уточнити за вимогами (часовий пояс зони й те, у якому поясі вводиться datetime-local)`; код приймає `Europe/Kyiv` (`lib/curfew.ts`).
