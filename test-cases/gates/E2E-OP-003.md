# E2E-OP-003: «Check before submitting» для вікна 23:30–00:15 у KBP-CTR-3 (повністю в curfew 23:00–05:00) → гейт TIME_WINDOW = fail

**Doc ref:** `SD/06 — Business Rules#1.4 TIME_WINDOW`, `SD/06 — Business Rules#4. Zone catalogue`, `SD/04 — Frontend Scope#Operator portal`, `components/FlightRequestPanel.tsx`, `components/GateResultsPanel.tsx`, `SD/03 — API Contract#The 422 body`, `SD/03 — API Contract#Gate pipeline (shared by submit and validate)`
**Role(s):** Operator (L2, ACTIVE) — залогінений
**Preconditions:**
- Оператор з `authorisation_level` = `L2` і `status` = `ACTIVE` залогінений (у шапці видно `operator-session-info`).
- Пілот цього оператора: `rating` = `R_ADVANCED`, `certified_on` = дата за 2 місяці до `window_start`.
- ЛА цього оператора: `mtom_grams` = `700` (смуга `C0`).
- Заявка у `DRAFT` для цього пілота й ЛА: `zone_code` = `KBP-CTR-3`, `requested_altitude_metres` = `50`, `window_start` = 23:30 місцевого часу зони дати, що настає через 7 днів, `window_end` = 00:15 наступної доби (45 хвилин; усе вікно всередині curfew).
- Браузер працює в часовому поясі `Europe/Kyiv` (щоб значення `datetime-local` збігалося з місцевим часом зони).
- У браузері відкрито DevTools → Network (запис мережі ввімкнено до кроку 2).

**Steps:**
1. Відкрити сторінку деталей цієї заявки `/operator/requests/<id>`.
2. Натиснути `flight-request-validate-button`.

**Expected result:** Картка `flight-request-gate-result-TIME_WINDOW` показує `fail` (атрибут `data-gate-status` = `FAIL`); у Network відповідь на `POST /api/v1/flight-requests/<id>/validate` має код `422`, а в її тілі `failing_gate` = `TIME_WINDOW` і `rule_reference` = `A-7 §1`.

**Rationale:** Позитивний клас невалідності правила «Curfew» гейту `TIME_WINDOW`: за `SD/06#1.4` жодна частина вікна не може потрапляти в curfew зони; для `KBP-CTR-3` curfew 23:00–05:00 (`SD/06#4. Zone catalogue`, `A-7` §1). Кнопка «Check before submitting» за `SD/04#Operator portal` показує результат по гейтах без зміни стану. Решта умов валідна (лід-тайм 7 днів, тривалість 45 хв, рейтинг, смуга `C0`, висота 50 м ≤ 120 м, `L2` ≥ `L2`), тому раніше жоден гейт не спрацьовує. Часовий пояс «місцевого часу зони» у docs не зазначено — `TODO: уточнити за вимогами (часовий пояс зони й те, у якому поясі вводиться datetime-local)`; код приймає `Europe/Kyiv` (`lib/curfew.ts`). Атрибут `data-gate-status` і `data-testid` картки взято з коду, а не з docs. Текст причини перевіряє окремий кейс E2E-OP-007.
